## Design Notes
- `openai_agents_sdk`: I borrowed the explicit tools/guardrails/tracing model, but kept a local controller protocol so evals still run without an API key.
- `anthropic_effective_agents`: The project starts as a workflow on purpose: it locks down source provenance, state, and eval before introducing model autonomy.
- `langgraph`: I implemented the minimal state graph first, so I can explain exactly what LangGraph would replace.
- `mcp`: I did not start by shipping an MCP server; I first made tool contracts explicit enough that an MCP adapter has a clean boundary.
- `ragas`: The project is not judged by one demo prompt; it has fixed corpora, guardrail checks, and baseline delta.
- `crewai`: I can explain why this project is not multi-agent yet: the current bottleneck is eval and provenance.
- `openhands`: A serious agent project needs an inspectable product surface, not only an implementation path.
- `smolagents`: The project deliberately plans experiment execution later, after source and permission gates exist.
- `autogen`: I checked current project status before choosing what to borrow; not every popular repo should be adopted.
